# Power BI Desktop Integration Guide

This guide explains how to open and visualize the generated predictive maintenance tables in **Microsoft Power BI Desktop** (100% Free for Windows).

---

## 1. Exported Data Tables

When you execute `python main.py`, three clean CSV tables are automatically formatted and exported to `d:\Predict_Failure\data\processed\`:

1. **`powerbi_fleet_overview.csv`**: Contains the latest snapshot for every machine asset (Health Score, Failure Probability, Anomaly Score, Risk Tier, and current sensor readings).
2. **`powerbi_sensor_trends.csv`**: Chronological multi-sensor time-series logs (Air Temp, Process Temp, Speed, Torque, Tool Wear, Power, Temp Diff, and Machine Failure flags).
3. **`powerbi_alerts_queue.csv`**: Structured maintenance work orders generated by the Agent (Diagnosed failure mode, root-cause reasoning, recommended actions, urgency).

---

## 2. Setting Up Power BI Desktop (Step-by-Step)

### Step 1: Open Power BI Desktop & Load Data
1. Launch **Power BI Desktop**.
2. Click **Get Data** $\to$ **Text/CSV**.
3. Select `d:\Predict_Failure\data\processed\powerbi_fleet_overview.csv` and click **Load**.
4. Repeat for:
   - `powerbi_sensor_trends.csv`
   - `powerbi_alerts_queue.csv`

---

### Step 2: Build Page 1 — Executive Fleet Overview
1. **Fleet KPI Cards (Top Banner):**
   - Add a **Card** visual $\to$ Drag `powerbi_fleet_overview[product_id]` $\to$ Select aggregation **Count (Distinct)** $\to$ Label as "Monitored Machines" (10,000).
   - Add a **Card** visual $\to$ Drag `powerbi_fleet_overview[health_score]` $\to$ Select **Average** $\to$ Label as "Fleet Average Health" (~96%).
   - Add a **Card** visual $\to$ Drag `powerbi_alerts_queue[ticket_id]` $\to$ Select **Count** $\to$ Label as "Active Maintenance Work Orders".
2. **Risk Tier Donut Chart:**
   - Add a **Donut Chart** visual.
   - Legend: `risk_tier` (`NORMAL`, `WATCH`, `WARNING`, `CRITICAL`).
   - Values: Count of `product_id`.
3. **Asset Table:**
   - Add a **Table** visual with columns: `product_id`, `product_type`, `health_score`, `failure_probability_pct`, `risk_tier`.

---

### Step 3: Build Page 2 — Sensor Trend Analysis
1. **Interactive Machine Slicer:**
   - Add a **Slicer** visual $\to$ Field: `powerbi_sensor_trends[product_id]`.
2. **Temperature Dynamics (Line Chart):**
   - X-Axis: `timestamp`.
   - Y-Axis: `process_temp_k` and `air_temp_k`.
   - Tooltips: `temp_diff_k`.
3. **Mechanical Spindle Dynamics (Line Chart):**
   - X-Axis: `timestamp`.
   - Y-Axis: `rotational_speed_rpm` and `torque_nm`.
4. **Failure Probability & Health Index (Area Chart):**
   - X-Axis: `timestamp`.
   - Y-Axis: `failure_probability_pct` and `health_score`.

---

### Step 4: Build Page 3 — Maintenance Agent Work Orders
1. **Urgency Filter Slicer:**
   - Add a **Slicer** $\to$ Field: `urgency_level` (`IMMEDIATE`, `HIGH`, `MEDIUM`).
2. **Work Orders Grid:**
   - Add a **Table** visual:
     - `ticket_id`
     - `timestamp`
     - `equipment_id`
     - `diagnosed_failure_mode`
     - `root_cause_explanation`
     - `recommended_action`
     - `urgency_level`

---

## 3. Save as `.pbix`

Once styled, click **File $\to$ Save As** $\to$ `dashboard\Predictive_Maintenance.pbix`.  
The file can be shared or presented on any Windows machine running free Power BI Desktop!
